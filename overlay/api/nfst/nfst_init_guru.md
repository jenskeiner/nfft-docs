Creates a d-dimensional transform plan.

Parameters:

`ths_plan`
:   The plan for the transform

`d`
:   the dimension

`N`
:   The bandwidths

`M_total`
:   The number of nodes $x$

`n`
:   The oversampled bandwidths

`m`
:   The cut-off parameter

`flags`
:   The flags known to nfst

`fftw_flags`
:   The flags known to fftw
