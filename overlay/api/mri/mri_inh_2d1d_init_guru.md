Creates a transform plan.

Parameters:

`ths`
:   The plan for the transform

`N`
:   The bandwidth $N$

:   The number of nodes $x$

`n`
:   The oversampled bandwidth $N$

`m`
:   The cut-off parameter

`sigma`
:   The oversampling factor

`nfft_flags`
:   The flags of the NFFT plan

`fftw_flags`
:   The flags of the FFTW
