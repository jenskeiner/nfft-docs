Creates a transform plan.

Parameters:

`plan`
:   a pointer to a `nfsft_plan` structure

`N`
:   the bandwidth $N \in \mathbb{N}_0$

`M`
:   the number of nodes $M \in \mathbb{N}$

`nfsft_flags`
:   the NFSFT flags

`nfft_flags`
:   the NFFT flags

`nfft_cutoff`
:   the NFFT cutoff parameter
