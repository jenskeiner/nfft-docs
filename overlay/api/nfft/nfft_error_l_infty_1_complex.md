Computes the error $\|x-y\|_\infty / \|z\|_1$ of two complex vectors, where $\|z\|_1 = \sum_j |z_j|$.

Parameters:

`x`
:   The reference vector

`y`
:   The vector to compare

`n`
:   The length of `x` and `y`

`z`
:   The vector for the normalisation

`m`
:   The length of `z`
