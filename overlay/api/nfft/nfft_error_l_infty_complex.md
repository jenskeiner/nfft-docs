Computes the relative error $\|x-y\|_\infty / \|x\|_\infty$ of two complex vectors, where $\|x\|_\infty = \max_j |x_j|$.

Parameters:

`x`
:   The reference vector

`y`
:   The vector to compare

`n`
:   The length of `x` and `y`
