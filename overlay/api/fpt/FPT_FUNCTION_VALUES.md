---
symbol: FPT_FUNCTION_VALUES
kind: flag
source: header
---
If this flag is set, the output is the vector of function values at the
Chebyshev nodes $\cos\bigl(\pi(j+\tfrac12)/(k_{\mathrm{end}}+1)\bigr)$,
$j=0,\ldots,k_{\mathrm{end}}$, rather than the Chebyshev coefficients. Pass
it to the transform routines.
