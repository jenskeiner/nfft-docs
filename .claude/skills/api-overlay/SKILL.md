# API overlay

The API reference `doc/api/*.md` is generated by `support/apigen` from
`nfft/include/nfft3.h`. Text in `overlay/api/<module>/<key>.md` replaces the
header text for that symbol. The header is upstream; you never edit it.

## Find the gaps

```
uv run python -m support.apigen
python3 -c "import json; c=json.load(open('doc/api/coverage.json')); print([f'{m}/{k}' for m,d in c['modules'].items() for k,v in d['symbols'].items() if v=='none'])"
```

## File format

Path `overlay/api/<module>/<key>.md`. `<key>` is the double-precision public
name: `nfft_trafo`, `nfft_plan`, `nfsoft_SO3_fpt`. Flags and helper macros
use their plain name: `PRE_PHI_HUT`, `NFSFT_INDEX`.

```
---
symbol: nfft_trafo
kind: function
source: agent
---
Computes the NFFT, the sums $f_j = \sum_{\mathbf{k} \in I_N^d} \hat f_{\mathbf{k}} \mathrm{e}^{-2\pi\mathrm{i}\mathbf{k}\mathbf{x}_j}$, for the nodes and coefficients stored in the plan.

`ths`
:   The plan. `nfft_precompute_one_psi` must have run when the plan has a `PRE_*_PSI` flag.

Reads `f_hat`, writes `f`. See `nfft/kernel/nfft/nfft.c`, `nfft_trafo`.
```

`kind` is one of `function`, `struct`, `typedef`, `variable`, `flag`,
`macro`. A struct file holds the struct text, then one `### member` section
per member you describe:

```
---
symbol: nfsoft_plan
kind: struct
source: agent
---
Plan of a transform on the rotation group.

### N_total

Number of coefficients, `NFSOFT_F_HAT_SIZE(N)`.
```

## What a function entry says

1. What it computes, one sentence, with the formula if there is one.
2. Each parameter as a definition list entry, name in backticks.
3. Preconditions: which precompute or init must have run, which flags matter.
4. What it reads and writes in the plan.
5. Where the code is: `nfft/kernel/<module>/<file>.c`, function name.

Read the implementation before writing. The signature is in `doc/api/`.
Do not describe what the name suggests, describe what the code does.
